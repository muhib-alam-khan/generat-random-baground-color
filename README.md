# Random Background Color Generator

A simple, elegant web application that generates random background colors with a smooth transition effect. Perfect for designers, developers, or anyone looking for color inspiration.

## Features

- **Random Color Generation**: Click the "Generate Color" button to instantly change the background to a random RGB color.
- **Color Display**: View the current color's RGB value in a dedicated display area.
- **Reset Functionality**: Easily reset the background to the default white color.
- **Smooth Transitions**: Enjoy a 0.5-second ease transition when colors change.
- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Modern UI**: Clean, professional interface with hover effects and shadows.

## How to Use

1. Open `index.html` in your web browser.
2. Click the **Generate Color** button to change the background to a random color.
3. The RGB value of the current color will be displayed below the title.
4. Click **Reset** to return to the default white background.

## Technologies Used

- **HTML5**: Structure and content
- **CSS3**: Styling, animations, and responsive design
- **JavaScript (ES6)**: Color generation logic and DOM manipulation
- **Google Fonts**: Roboto font for a clean, modern look

## Browser Support

Works in all modern browsers that support CSS transitions and ES6 JavaScript.

## Customization

Feel free to modify the code to:
- Change the color generation algorithm (e.g., to HSL or hex)
- Adjust the transition duration
- Add more color formats (hex, HSL)
- Implement color saving or favorites functionality
